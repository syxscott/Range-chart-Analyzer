## 已修复(本轮)

| 编号 | 严重度 | 问题 | 修复 |
|---|---|---|---|
| B1 | **阻断** | `server.py` 对静态资源下发 `CSP: default-src 'self'`,`img-src` 未含 `data:` → 上传预览被拦、`handleFile` 在 dataUrl 赋值前 reject,**后端模式下提取完全不可用**;且内联 `style="…"`(index.html:145、table.js 的 raw-response `<pre>`)被剥样式 | CSP 改为 `default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'`(`script-src` 仍回退 `'self'`,脚本安全姿态不变);新增回归测试 `TestServerCSPHeader` |
| H1 | 高 | force-rerun 按钮在**首次**成功提取后不出现:`setBusy(false)` 在 `finally` 中先于 `state.result = res.data` 执行,可见性判断读到旧 null,且渲染后无重估 | 抽出 `updateActionButtons()`:setBusy 与结果存储后都调用;新增前端行为测试(138 项套件) |

## 实测通过(无 bug)

- **全流程**:上传预览(尺寸/体积元信息)→ 自动判图 → 提取(mock)→ 4 表渲染(物种斜体、置信度环、质量徽章、一致性 pill 3/3 绿 1/3 红、嵌合警告)→ 复制 TSV → 下载 CSV/JSON
- **错误路径**:HTTP 500 → 红警 + 详情 + 按钮状态恢复;空数据 → 各表「(此项无数据)」;取消 → toast「已取消提取。」;连点防抖(不重复发请求);失败后旧结果保留
- **i18n**:zh/en/ja 切换全联动(表头 Species/Agreement、種/一致度),无残留 key 串
- **主题**:三态切换(system/light/dark)颜色全生效
- **响应式**:1280/900/768/375/320 无页面级横向滚动;375px 工具栏正常换行
- **a11y**:表格 aria-label/scope、滑杆 aria-describedby、radiogroup 方向键、dropzone 键盘 Enter、焦点环可见
- **console**:剥离 CSP 后其余操作零 error、零 pageerror

## 建议(未改,属功能/打磨决策)

1. **M4(功能缺失)**:README 声称"表格可在线编辑(双击单元格)、可新增/删除行",但 Web 前端**没有编辑功能**(仅桌面 GUI 有)——已修正 README 表述;若产品上需要 Web 端编辑,建议单独实现(双击单元格 → 写回 `state.result` → 重渲染,删除行需处理导出对齐)。
2. **Nit1**:主题/语言切换组 `overflow:hidden` 裁切首末按钮焦点环(改 padding 或 outline-offset)。
3. **Nit2**:置信度环与导出按钮底边差 ~7px 基线错位(微调 align-items)。
4. **Nit4**:语言按钮用 CN/EN/JA 而非本地语言名(中文界面里"中文/English/日本語"更友好)。
5. **布局建议**:设置卡占首屏 ~562px,上传卡主操作(提取按钮)落于折线以下——窄屏首屏看不到主操作;空数据结果区只有 4 个「(此项无数据)」+ 低置信度环,可加一句显式提示。
