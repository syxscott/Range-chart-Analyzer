## 前端 UI bug 审查（独立静态 + Playwright 实测）

方法：静态读 index.html / css/style.css / js/app.js 交互逻辑；启动 server.py @ 127.0.0.1:8765 + Playwright (Edge channel) mock /api/extract，跑 13 项 DOM/计算样式/对比度探针 + 5 张全屏截图。

**确认的 UI 缺陷（按严重度）：**
1. **高 · chart-mode 缺 phylogenetic_tree 选项**（index.html:158 + js/app.js rcaResolveChartMode:87 + rcaAutoDetectChartMode:46-80）—— Web 前端（直连/后端）无法手动或 auto 检测选 phylogenetic_tree 模式；Python 端支持 4 模式但 Web 端缺一个选项 + auto 关键字。功能性缺陷。
2. **高 · 暗色 segmented 选中态对比度 2.54:1**（css/style.css:651）—— `.segmented button[aria-checked="true"] { background: var(--primary-color); color: #fff }` 在暗色下 #60a5fa+白字不达 WCAG AA 4.5:1（实测 2.54）。08-01 M1 修了 lang-switch/theme-toggle 但漏了 segmented。"自动"/"后端"/"浏览器直连" 三按钮选中态文字几乎看不清。
3. **中 · 结果表长文本截断无 title**（css/style.css:980-985 + js/table.js rcaRenderResults:283）—— 所有 td 默认 `white-space:nowrap; max-width:280px; overflow:hidden; text-overflow:ellipsis`；CSS 注释承诺 "full value via title" 但 table.js 渲染未设 title 属性（实测 hasTitle:false, scrollWidth 625 > clientWidth 280）。sections 名/coordinates、formations、other_fossils、biozone age 长文本只能看截断尾巴。
4. **中 · `--surface` 未定义 → quality-badge 背景透明**（css/style.css:811）—— `.quality-badge { background: var(--surface) }` 但 `:root` 块从未定义 `--surface`。该声明无效，背景回退 transparent。徽章仅靠 border 显示。
5. **低 · confidence label 样式选择器错位**（css/style.css:791 + js/table.js:202）—— `.confidence-ring .label` 选了后代，但 table.js 把 label 渲染为 ring 的兄弟 span。font-size 应 12px 实际 14px、无 uppercase、无 margin-left。
6. **低 · sticky 序号列奇数行背景透明**（css/style.css:1013-1014）—— 偶数行 td:first-child 有 zebra 背景，奇数行 transparent。横向滚动时，序号列下方表格内容会透出。

**实测通过（非 bug）**：agreement pill（3/3 good / 1/3 low / 2/3 good）；嵌合警告 alert；i18n 三语切换无残留 key；375px 无横向滚动；无 console error / pageerror；dropzone 键盘可达；image preview / caption counter / 响应式布局。
